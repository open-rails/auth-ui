# @openrails/auth-ui (moved)

This repository is archived. `@openrails/auth-ui` now lives in AuthKit at
[`sdk/auth-ui`](https://github.com/open-rails/authkit/tree/master/sdk/auth-ui),
with its full history, and ships with every AuthKit release:

```json
"@openrails/auth-ui": "https://github.com/open-rails/authkit/releases/download/vX.Y.Z/openrails-auth-ui-X.Y.Z.tgz"
```

The existing `v0.x` release archives here stay downloadable.
